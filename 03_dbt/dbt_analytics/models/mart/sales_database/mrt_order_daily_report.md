{% docs mrt_order_daily_report %}

This mart model provides daily order performance metrics by state and account manager.
The model aggregates customer order data to support business reporting and operational analysis.

Main metrics included in this model:
- **Number of Orders**: Total number of orders created for a given day and region.
- **Average Items per Order**: Average quantity of items included in each order.
- **Average Feedback Score per Order**: Average customer satisfaction score for orders.
- **Average Total Amount per Order**: Average monetary value of customer orders.
- **Account Manager**: Account manager responsible for the region.
- **State**: Customer state associated with the order.

The model is mainly used for daily sales reporting, regional performance analysis, and account manager monitoring.
