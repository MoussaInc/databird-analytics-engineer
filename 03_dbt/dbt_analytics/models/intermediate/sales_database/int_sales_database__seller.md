{% docs int_sales_database__seller %}

This model provides seller-level performance metrics by combining order item and customer feedback data.
The model is used to evaluate seller performance based on revenue generation and customer satisfaction.

Main metrics included in this model:
- **Total Revenue**: Total revenue generated by the seller from all sold products.
- **Average Feedback Score**: Average customer review score for orders associated with the seller.
- **Seller ID**: Unique identifier of the seller.

This model is mainly used for seller performance analysis, business reporting, and operational monitoring.
